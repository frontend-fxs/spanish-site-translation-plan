# Empieza aquí (Product Owner)

Este plan vive en **GitHub**: los enlaces del markdown se pueden seguir y los CSV se pueden descargar.

Trabaja sobre la carpeta [`producto/`](./) (este directorio). La carpeta `tecnico/` es solo para ingeniería.

## Cómo usar el repo

1. Abre este archivo en GitHub (vista previa del `.md`).
2. Haz clic en los enlaces de abajo: GitHub abre el archivo o la carpeta.
3. En un CSV: botón **Download raw file** (o Raw → guardar) para enviarlo al traductor / abrirlo en Excel o Sheets.
4. Cuando el traductor devuelva el CSV, súbelo al mismo path (PR o commit) y avisa a ingeniería.

## Orden de trabajo

1. [INFORME-product-owner.md](./INFORME-product-owner.md) → cierra decisiones P1–P20.
2. Por cada lote: ficha en [ordenes/](./ordenes/) + CSV en [adjuntos/](./adjuntos/).
3. Guarda los CSV revisados en la **misma ruta** del lote.
4. Avisa a ingeniería para reintegrar.
